# 섬 탭 다이어트 — 심플 · 직관 · 트렌디 재설계

## Summary

섬 탭이 **성격검사 리포트 + 3모드 대시보드 + 카드 7장**으로 비대해졌다.
"심심풀이 + 펫"이라는 영혼([[product-refocus-cold-audit]])과 정반대로, 다마고치를 켰는데 대시보드가 열린다.
해결: **주인공을 펫 하나로 못 박고, 모드 탭과 무거운 카드를 걷어내 단일 스크롤로.**
2026 트렌드(미니멀·싱글포커스·클린 HUD·플레이풀 마이크로인터랙션)와도 정확히 일치한다.

> 한 줄: **섬 탭 = "펫이 사는 집" 한 화면. 분석·정체성·꾸미기는 뒤로 숨긴다.**

## Context — 지금 섬 탭에 쌓인 것 (실측)

위→아래로 실제로 올라가 있는 것:

1. topBar(성향 섬 + 조개)
2. PetAwayCard(재방문 카드 — 최근 추가, 유지)
3. **IslandTypeCard** — 16타입·군도·항해수식어·궁합(88%)·내 섬 공유  ← 무겁다
4. 게스트 배너
5. 펫/섬 hero(나의 섬)
6. **IslandModeTabs — 발견 / 가지 지도 / 꾸미기** 3모드
   - 발견: TodayDiscoveryCard + PetOriginCard + PetDiaryCard + WeeklyRecapCard + InsightMapPreview (카드 5장)
   - 가지 지도: InsightMapPreview (또 등장 — 중복)
   - 꾸미기: 테마 가챠/장식
7. ThemeProbabilitySheet(모달)

**문제**: 한 탭에 (a) 무거운 정체성 리포트, (b) 3개로 갈라지는 모드, (c) 발견 모드에만 카드 5장, (d) 인사이트맵 2중복. 첫 진입에서 눈이 갈 곳을 못 찾는다 = "복잡".

## Details

### 설계 3원칙

| 원칙 | 정의 | 적용 |
|---|---|---|
| **심플** | 한 화면에 주인공 하나 | 펫 히어로만 크게. 카드 7장 → 3장 이하 |
| **직관** | 모드 전환·설명 없이 스크롤로 이해 | 3모드 탭 제거 → 단일 세로 스크롤 |
| **트렌디** | 클린 HUD + 펫 마이크로인터랙션 | 조개/레벨은 작게, 펫은 움직이고 탭에 반응 |

### 새 섬 탭 IA (단일 스크롤, 모드 탭 없음)

```
┌─────────────────────────────┐
│ 내 섬            🐚 1,240    │  ← 클린 HUD: 조개/레벨 작게 우상단
│                             │
│        (크고 움직이는 펫)     │  ← 주인공. idle 애니, 탭하면 폴짝+한마디
│        데구르 · Lv.3         │
│     기분 ●●●●○  에너지 ●●●○○ │  ← 미니 게이지만(숫자 X)
│                             │
│   [ 🍖 간식 ]  [ ✋ 쓰다듬기 ] │  ← 가벼운 돌봄 1줄(플레이풀)
├─────────────────────────────┤
│ 🐾 부재중 카드(있을 때만)      │  ← 재방문 훅(유지)
├─────────────────────────────┤
│ 💬 "요즘 너, 익숙한 걸 고르더라"│  ← 자기발견 '한 줄'(은근). 리포트 아님
│                  자세히 ›    │  ← 깊은 분석은 탭하면 별도 화면
├─────────────────────────────┤
│ [ 🎁 펫 뽑기 ]  [ 🎨 꾸미기 ] │  ← 가챠/꾸미기는 작은 진입 버튼(별도 화면)
└─────────────────────────────┘
```

핵심: **펫 하나가 화면의 70%.** 나머지는 한 줄짜리거나 진입 버튼.

### 가져갈 것 / 접을 것 (현재 요소별 처분)

| 현재 요소 | 처분 | 이유 |
|---|---|---|
| 펫/섬 hero | ✅ **주인공으로 승격** | 더 크게, 애니·탭반응. 이게 섬 탭의 전부 |
| PetAwayCard | ✅ 유지 | 재방문 훅 |
| 조개 지갑 | ✅ 클린 HUD로 축소 | 작게 우상단 |
| 돌봄(간식/놀기) | ✅ 1줄로 노출 | 가벼운 상호작용 |
| PetDiaryCard | 🔧 **"한 줄"로 압축** | 카드 → 자기발견 한 줄. 날짜/장식 제거 |
| **IslandTypeCard**(16타입·궁합·공유) | 🅿️ **홈에서 제거(PARK)** | 무거운 MBTI 아류. 영혼과 반대 |
| **IslandModeTabs**(발견/가지지도/꾸미기) | ❌ **제거** | 단일 스크롤로. 모드 전환 자체가 복잡 |
| InsightMapPreview(×2 중복) | 🔧 "자세히 ›" 링크로 | 깊은 시각화는 `/insight` 별도 화면에만 |
| WeeklyRecapCard | 🅿️ 접기 | 주간 회고는 알림/별도로 |
| TodayDiscoveryCard, PetOriginCard | 🔧 펫 히어로/한 줄에 흡수 | 중복 정보 통합 |
| 성향 조각/상위 성향 | ➡️ `/insight`로 이동 | 분석 화면에 모음 |
| 테마 가챠/꾸미기 | ➡️ **별도 화면**, 버튼만 | 메인에서 내리되 진입은 유지 |

> PARK = 삭제 아님. 코드/마이그레이션 그대로 두고 **홈 노출만 제거**(라이브 DB라 비용 0).
> "자세히 ›", "꾸미기", "펫 뽑기"는 화면을 **나누는** 것 — 기능은 살되 첫 화면은 비운다.

### 트렌디 = 인터랙션으로 (텍스트로 채우지 말 것)

- **클린 HUD**: 조개/레벨/게이지는 작게·아이콘 위주, 숫자 최소(`80/100` → 게이지 점).
- **펫 마이크로인터랙션**: idle 흔들림, 탭하면 폴짝 + 말풍선 한마디(이미 heart 애니 인프라 있음 → 재활용).
- **부드러운 전환**: 카드 등장 슬라이드, 보상 받을 때 조개 튀는 모션.
- **여백**: 카드 사이 간격↑, 한 화면에 정보 밀도↓. (트렌드: clutter-free, 핵심만)

### 실행 단계 (작게)

1. **P0 — 다이어트(구조)**: `IslandModeTabs` 제거 → 단일 스크롤. `IslandTypeCard` 홈에서 내림. 인사이트맵·주간회고·성향조각을 `/insight`로 이동, 섬엔 "자세히 ›" 링크만.
2. **P1 — 한 줄화**: PetDiaryCard → 자기발견 한 줄 + "자세히 ›". 돌봄 버튼 1줄 노출.
3. **P2 — 트렌디 비주얼**: 펫 크게 + 탭 반응 + 클린 HUD 게이지. 가챠/꾸미기 진입 버튼화.
4. (검증) 첫 진입 3초 안에 "내 펫이다"가 보이는가 / 스크롤 없이 핵심이 한눈에 들어오는가.

### 안티패턴

- 첫 화면에 **분석 리포트·정체성·모드 선택**을 두지 말 것. 펫이 먼저, 분석은 "자세히 ›" 뒤.
- 빈 곳을 **카드로 메우지 말 것.** 여백이 트렌디다.
- "트렌디 = 요소 추가"가 아니라 **"요소 제거 + 인터랙션".**
- 기능을 지우는 게 아니라 **화면을 나눈다**(가챠·인사이트·꾸미기는 살아있되 별도 화면).
