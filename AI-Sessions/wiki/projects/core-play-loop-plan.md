# 핵심 놀이 루프 계획서 — "예쁜 설정집"에서 "손가락이 먼저 움직이는 앱"으로

## Summary

문제는 기능 부족이 아니라 **코어 동사(verb)의 부재**다.
유저가 첫 화면에서 "내가 뭘 하는 건데?"가 흐릿한 이유는, 세계관(섬·펫·성향)은 풍부한데
**3초 안에 손가락이 닿을 단 하나의 행동**이 전면에 없기 때문이다.

해결책은 새 시스템이 아니라, **이미 있는 3개 자산(여론 피드 / 펫 / 궁합)을 "고른다(탭)"는 동사 하나로 재배치**하는 것.
세 반응 각각에 대응하는 검증된 메커니즘이 존재한다:

| 유저가 해야 할 말 | 검증된 메커니즘 | 레퍼런스 | 현재 코드 |
|---|---|---|---|
| "친구한테 바로 보내야겠다" | **여론 reveal + 도전장 공유** (리포트가 아니라 "넌 뭐 고를래?") | PIKU 이상형월드컵, Smile Dating Test(TikTok) | `BalanceCard` 여론바 있음 / 공유는 약함 |
| "내 펫이 뭘 했는지 또 보고 싶다" | **펫이 부재중에 한 일 + 가변 보상** (방치=상실, 내 선택에 반응) | 다마고치 habit loop | 펫 알→진화 있음 / "한 일" 없음 |
| "우리 둘이 붙이면 무슨 일?" | **가벼운 충돌(% 일치 + 갈린 지점)** — 16타입 리포트 아님 | PersonalityMatch, Smile Test 친구 비교 | 궁합 인프라 있음(PARK·무거움) |

> 한 줄: **코어는 "A vs B를 탭한다." 나머지 셋은 그 탭에 붙는 즙(juice)일 뿐이다.**

## Context — 조사에서 얻은 핵심 원리

1. **PIKU(이상형 월드컵)** — 한국에서 밸런스게임이 바이럴된 진짜 이유는 (a) **탭-탭-탭 토너먼트**라는 손맛, (b) 유저가 직접 만들고 **공유**, (c) 스트리머 콘텐츠화. 결과 리포트가 아니라 **"고르는 행위 자체"가 중독**이었다.
2. **다마고치** — 재방문은 보상이 아니라 **정서적 애착 + 가변 보상**에서 온다. "방치하면 잃는다"는 인간적 상실감이 streak보다 강하다. 핵심: 펫이 **내 선택에 반응**해서 "내 것"이 되어야 한다. 모바일에서 루프는 더 짧고 빨라졌다.
3. **Smile Dating Test / PersonalityMatch** — 바이럴 산물은 **"비교를 부르는 결과"**. 링크 공유 → 친구가 풀고 → 0~100% + **어디서 갈렸나**를 본다. 공유물은 자랑(report)이 아니라 **대결장(challenge)**일 때 퍼진다.

공통 결론: **공유물 = 리포트가 아니라 도전장. 재방문 = 보상이 아니라 애착. 충돌 = 진단이 아니라 "어디서 갈렸나".**

## Details

### 0. 첫 화면 재설계 — 코어 동사를 전면에

지금: 첫 화면이 섬/성향카드/펫 등 **설정**으로 시작 → "뭘 하지?".
바꾼다: 첫 화면 = **오늘의 밸런스 한 장이 화면을 가득 채운 큰 A|B 카드.** 그게 전부.

```
┌─────────────────────────────┐
│  Q. 안 친한 친구 결혼식       │   ← 공감되는 실생활 고민(여론형 질문)
│  ┌────────┐   ┌────────┐    │
│  │ 안 가고 │vs│ 참석하고 │    │   ← 손가락이 바로 닿는 큰 두 버튼
│  │ 5만원   │   │ 10만원  │    │
│  └────────┘   └────────┘    │
└─────────────────────────────┘
        ↓ (탭하는 순간)
   "남들은 73%가 B!" 여론 reveal  ← 도파민 ①
   + 펫이 폴짝 "오 너 소수파네?" ← 도파민 ②(펫 반응)
   + [친구한테 물어보기] 한 버튼  ← 도파민 ③(도전장)
```

탭 1회 = 여론(①) + 펫 반응(②) + 공유 도전장(③)이 **동시에** 터진다. 세 반응이 한 동작에서 나온다.

### 1. 반응 ①: "친구한테 바로 보내야겠다" — 여론 도전장

핵심 전환: **공유물을 "내 성향 리포트"에서 "이 질문, 너라면?" 도전장으로.**

- 투표 직후 결과바를 **더 세게**: "73% B" + **소수파/다수파 뱃지**("넌 27% 소수파 🔥"). 반전일수록 크게.
- **[친구한테 물어보기]** 한 버튼 → 친구는 **로그인 없이** 답하는 질문 페이지(`/q/[id]`)로 착지.
  - 친구가 고르면 → 즉시 "너=B, 보낸 사람=A, 남들=73% B" 3자 비교 → **여기서 설치 유도.**
  - (기존 `/guess/[id]` 무로그인 패턴을 그대로 재사용 — 인프라 이미 있음)
- 공유 문구도 도전장 톤: *"안 친한 친구 결혼식, 5만 안 가 vs 10만 가. 넌? 👀"*

> 왜 작동하나: PIKU·Smile Test 모두 **"비교를 부르는 한 질문"**이 퍼졌다. 자기 자랑 카드는 안 퍼진다.
> 이게 **획득(acquisition)** 엔진. 무로그인 착지 → 비교 → 설치.

### 2. 반응 ②: "내 펫이 뭘 했는지 또 보고 싶다" — 부재중 일기 + 가변 보상

핵심 전환: 펫을 **장식(static)에서 "내가 없는 동안 뭔가 한 존재"로.**

- **재방문 트리거 카드**: 앱을 다시 열면 *"네가 없는 동안 데구르(펫)가 ___ 했어"*
  - 내 선택 패턴에 반응한 한 줄: *"너 요즘 '혼자' 많이 골라서, 데구르가 조용한 동굴을 찾았대."* (성향엔진 뒤에서 조용히 구동 — 전면 노출 X)
  - **가변 보상**: 가끔 조개/희귀 아이템을 물고 옴(매번 X, 랜덤). 다마고치식 "또 뭐 가져왔나" 기대.
- **매 투표마다 펫이 즉각 반응**(폴짝/말풍선 1줄). 탭의 즉각 피드백.
- **방치 = 약한 상실**(과하지 않게): 며칠 안 오면 펫이 시무룩한 한 줄. 죄책감이 아니라 그리움 수준.

> 왜 작동하나: 다마고치 재방문은 보상이 아니라 **애착 + 가변성**. 펫이 *내 선택에* 반응해야 "내 펫"이 된다.
> 이게 **리텐션(retention)** 엔진.

### 3. 반응 ③: "우리 둘이 붙이면 무슨 일?" — 가벼운 충돌(% 일치)

핵심 전환: 무거운 16타입 궁합 리포트를 **버리고**, **"우리 답 몇 % 같아?"**만 가볍게.

- **둘이 붙이기**: 친구 링크 공유 → 둘 다 **같은 5~10문제**를 풀면 → **"우리 78% 통해"** + **가장 많이 갈린 1~2질문**("근데 '회식 끝까지 vs 1차만'에서 정반대 😂").
- 산물은 진단이 아니라 **"어디서 갈렸나"라는 떡밥** — 대화가 시작됨(연인/친구가 서로 보냄).
- 기존 궁합 점수 인프라를 **trait 축이 아니라 실제 질문 답 일치율**로 재활용(가볍고 즉시 이해됨).
- 16타입/군도/항해수식어/`/compat` 무거운 화면은 **PARK 유지**(cold-audit 결정 준수).

> 왜 작동하나: Smile Test·PersonalityMatch 바이럴은 **링크→친구가 풂→% + 갈린 점 비교**. 이게 **K-factor(전파)** 엔진.

### 무엇을 만들고 / 재활용하고 / 버리나 (현 코드 기준)

| | 항목 | 처분 |
|---|---|---|
| ♻️ 재활용 | `BalanceCard` 여론바 → 소수파 뱃지+도전장 버튼 강화 | 작음 |
| ♻️ 재활용 | `/guess/[id]` 무로그인 패턴 → `/q/[id]` 무로그인 투표 착지 | 작음 |
| ♻️ 재활용 | 궁합 점수 함수 → trait축 대신 **답 일치율**로 라이트화 | 중간 |
| 🆕 신규 | 펫 "부재중 한 일" 일기 카드 + 가변 보상 1종 | 중간 |

| 🅿️ 동결 | 16타입·군도·궁합 리포트·친구추측 무거운 버전 | 유지(내림) |

### 우선순위 (작게, 산으로 안 가게)

- **P0 — 반응①(획득)**: 여론 reveal 강화 + 소수파 뱃지 + **[친구한테 물어보기]** 도전장 → 무로그인 `/q/[id]` 착지 + 3자 비교.
  *가장 싸고, 가장 바이럴. 기존 피드/여론/무로그인 패턴 거의 재활용.*
- **P1 — 반응②(리텐션)**: 펫 "부재중 한 일" 재방문 카드 + 투표 시 펫 즉각 반응 + 가변 보상 1종.
- **P2 — 반응③(전파)**: "둘이 붙이기" 답 일치율 + 갈린 질문. (P0의 무로그인 착지 인프라 위에 얹음)
- (안 함) 16타입/궁합 리포트 부활, 임베딩 확장, 새 카테고리 — **전부 보류.**

### 성공 지표 (반응당 딱 1개)

- ① 공유율: **투표 → [친구한테 물어보기] 클릭률**, 무로그인 착지 → 설치 전환.
- ② 재방문: **D1 리텐션**(부재중 카드 본 비율), 펫 상호작용/세션.
- ③ 전파(K): **둘이 붙이기 완료 쌍 수**, 1인당 초대 발송.

### 안티 패턴 (다시 "설정집"으로 안 가려면)

- 첫 화면에 **설명/성향카드/설정을 먼저 보여주지 말 것.** 행동(A|B 탭)이 먼저, 의미는 부산물.
- 공유물은 **자랑 카드가 아니라 도전장.** "나는 ○○섬" < "넌 뭐 고를래?".
- 펫은 **꾸미기 대상이 아니라 반응하는 존재.** 정적 일러스트면 죽은 기능.
- 새 축·새 타입·새 카테고리로 **깊이를 더하지 말 것.** 같은 코어 동사에 **즙을 더 짜라.**
