# 냉철한 제품 가지치기 — "산으로 간 것" 잘라내기

## 진짜 북극성 (사용자 원래 의도)

> "재미삼아 심심풀이로 밸런스 게임하다 보면 **나도 몰랐던 나**를 알게 되고,
> **고민·궁금증**(예: *안 친한 친구 결혼식 안 가고 5만 vs 참석하고 10만*)을 물어보고 **여론**도 확인하고,
> **다마고찌 & 포켓몬처럼 펫을 한정판으로 뽑고 수집하는** 소소한 재미."

= 3개의 기둥. **이게 영혼이다.**

1. 🎮 **가벼운 놀이**: 심심풀이 밸런스 게임 (낮은 진입장벽, 한 손, 무겁지 않음)
2. 🪞 **은근한 자기발견 + 여론**: "어? 나 이런 사람이었네" + "남들은 이렇게 골랐네"
3. 🐣 **펫 수집(다마고찌+포켓몬)**: 돌보고, 한정판 뽑고, 모으는 감정적 중심

## 냉철한 진단: 무엇이 영혼이고, 무엇이 산인가

핵심 한 줄: **앱이 "가벼운 놀이+펫"에서 "무거운 성격검사 제품(MBTI 아류)"으로 표류했다.**
이번 세션에 만든 16섬·군도·항해수식어·궁합·친구추측은 **기술적으론 훌륭하지만 영혼과 반대 방향**이다.
다마고찌를 켰는데 16Personalities 리포트가 나오는 격.

## 가져갈 것 / 버릴 것 / 묻어둘 것

### ✅ 가져간다 (영혼 = 핵심)

| 항목 | 상태 | 비고 |
|---|---|---|
| 밸런스 게임 피드 + 투표 | 있음 | 코어 루프. 그대로 |
| **여론 분포(%) 결과바** | 있음(BalanceCard) | **이게 훅.** 투표 직후 "남들은 B 73%" 한 방을 더 강하게 |
| 질문 뱅크(453, 13카테고리) | 있음 | 유지하되 **"trait 균형" 강박 < "공감되는 고민" 콘텐츠**. 결혼식 5/10만 류 실생활 딜레마 비중↑ |
| 펫(돌봄·진화·말풍선) | 일부 있음 | **여기에 투자.** 다마고찌(돌봄) 강화 |
| **펫 한정판 가챠·수집 도감** | 인프라만 흩어짐 | **최우선 신규.** draw_theme_pack/rarity/조개경제 재활용 → 펫 중심 가챠+도감 ([[gacha-implementation-guide]] 참고) |
| 은근한 자기발견 | choice echo 있음 | 펫이 "요즘 너 ~한 거 같아" 정도. **프레임 노출 없이** |
| 5축 trait 엔진 | 있음 | **뒤에서 조용히** 펫 매칭·가벼운 코멘트 구동. 전면 노출 금지 |
| 중복/악용 방어 | 완료 | 유지만. **더 안 만든다** |

### ❌ 버린다 / 🅿️ 묻어둔다 (산 = 영혼과 충돌)

| 항목 | 처분 | 이유 |
|---|---|---|
| **16섬 TYPE + 군도 + 항해수식어** | 🅿️ PARK | 무겁고 MBTI 아류. "심심풀이"와 정반대. 코드/마이그레이션은 남기되 **전면에서 내림** |
| **궁합(/compat, island_compat_line, compute_island_compat)** | 🅿️ PARK | 관계앱 기능. 현 단계 핵심 아님 |
| **친구가 보는 내 섬(/guess, friend_guesses)** | 🅿️ PARK | 바이럴 훅이지만 무겁고 복잡. 나중에 가벼운 형태로만 |
| 의미 임베딩 dedup | 관리자 툴로만 보관 | 출시 전 과투자. 더 확장 X |
| 인사이트맵 모순 분석(무거운 시각화) | 후순위/단순화 | "가벼움"과 충돌. 펫 한 줄 코멘트로 대체 가능 |

> PARK = 삭제가 아니라 **메뉴/홈에서 내리고 동결**. 매몰비용에 휘둘리지 않되, 나중에 정말 필요하면 꺼낸다.
> (이미 라이브 마이그레이션이라 DB 객체는 둬도 비용 0. UI 노출만 제거.)

### 🔧 단순화

- "내 섬" = 16타입 정체성이 아니라 **펫이 사는 집 + 오늘의 나 한 줄** 정도로 가볍게.
- 섬 탭 상단의 IslandTypeCard(16타입/궁합/친구추측) → **펫 + 여론 요약 + 가벼운 한 줄**로 교체.
- 카테고리 13개 유지하되 분류/축균형 강박↓, 공감 고민 콘텐츠↑.

## 다시 정의한 한 줄 제품

> **"심심풀이 밸런스 게임 → 남들 여론 확인 → 내 선택이 키우는 한정판 펫 수집."**
> 자기발견은 부산물(은근), 펫이 감정의 중심, 여론이 사회적 훅. **MBTI 리포트가 아니다.**

핵심 루프(가볍게):
```
질문 1개 고른다 → "남들은 73% B!" 여론 한 방 → 조개/경험치 → 펫이 반응/성장
   → 가끔 한정판 펫 가챠 → 도감 한 칸 채움 → 또 한 문제
```

## 권고 로드맵 (영혼 회복 순)

1. **P0 — 섬 탭 다이어트**: IslandTypeCard(16타입·궁합·친구추측)를 홈에서 내리고, **펫 + 여론 + 한 줄 코멘트** 카드로 교체. (`/compat`,`/guess` 라우트는 비활성/숨김)
2. **P1 — 여론 훅 강화**: 투표 직후 "남들은 이렇게" 모먼트를 더 크게(반전 결과 강조, "소수파/다수파" 뱃지).
3. **P2 — 펫 가챠·도감(진짜 신규 투자)**: 한정판 펫 뽑기 + 수집 도감 + 다마고찌식 돌봄. (조개경제·draw_theme_pack·rarity 재활용, [[gacha-implementation-guide]])
4. **P3 — 고민형 질문 보강**: 결혼식 축의금 류 실생활 딜레마 + 여론 큐레이션.
5. (나중) 가벼운 공유: "이 질문 남들 결과" 캡처 공유 정도. 정체성/궁합 공유는 보류.

## 솔직한 메모

- 16섬/궁합/친구추측은 **내가 직전 두 메시지의 'MBTI 열풍' 요청을 충실히 구현한 결과**다. 기능 자체는 잘 돌아간다(라이브 검증됨). 다만 **그게 이 앱의 영혼은 아니다** — 지금 사용자의 말("소소한 재미·다마고찌·심심풀이")이 진짜 북극성이다.
- 바이럴 욕심(MBTI 정체성·궁합)과 영혼(가벼운 놀이·펫 수집)이 충돌할 때, **영혼을 택하라.** 정체성/궁합은 PARK 해두고, 나중에 펫·여론이 자리잡은 뒤 "가벼운 버전"으로만 부활시킨다.
- 진짜 미투자 영역은 **펫 가챠/수집**이다. 여기에 다음 에너지를 쏟는 게 맞다.
