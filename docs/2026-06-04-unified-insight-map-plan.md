## 1. 문제 (지금 왜 복잡한가)

원래 의도는 **"Obsidian의 연결 가시성 + 마인드맵의 위계 = 하나의 직관적 자기지도"**였습니다.
그런데 제가 Phase 2에서 이를 **3개 탭(발견 · 섬 지형 · 별자리)**으로 쪼갰고, 그 결과:

- 사용자가 **3개의 다른 정신 모델**(카드 / 공간 지형 / 추상 그래프)을 오가야 함 → 인지 부하 ↑
- "내 성향을 한눈에" 보려는 목적이 **탭 네비게이션에 가로막힘**
- 같은 데이터(성향·카테고리·근거질문·모순)를 세 군데 흩어 표현 → 중복·산만

> **핵심 진단:** 나눌 게 아니라 **합쳐야** 했다. 시안 #3가 정답 — 중심에 '나', 방사형 단일 지도 하나.

---

## 2. 목표 & 원칙

> **한 문장:** "탭 없이, **하나의 살아있는 마음 지도**를 손가락으로 탐험하며 나를 알아간다."

1. **One canvas (탭 제거).** 발견·지형·별자리를 **단일 마인드맵**으로 통합.
2. **점진 공개는 '네비게이션'이 아니라 '인터랙션'으로.** 기본은 깔끔한 전체 뷰 → 노드를 누르면 그 자리에서 펼쳐짐(focus/zoom). 화면 이동 없음.
3. **심플 = 동시에 보이는 요소 최소화.** 한 번에 중심 + 큰 가지 몇 개 + 한 줄 헤드라인. 나머지는 탭하면 드러남.
4. **트렌디 = 절제된 네온/글로우 + 부드러운 모션 1종**. 화려함보다 "내 우주" 같은 몰입감.
5. **Obsidian × 마인드맵 융합을 한 메타포로.**
   - 마인드맵 = 중심('나')에서 방사형 위계(나 → 성향축 → 카테고리 → 근거질문)
   - Obsidian = 로컬 그래프 포커스(노드 탭 → 그 노드 중심으로 재배치, 이웃만), 링크 라벨, 가중치 기반 노드 크기

## 3. 핵심 컨셉: "마음 지도(My Mind Map)" 단일 뷰

시안 #3를 제품화한 **하나의 화면**:

```
            ┌──────────── 오늘의 발견 (상단 떠 있는 한 줄 + 탭) ───────────┐
            │  "요즘 당신은 '안정'이 가장 진해지고 있어요"   [자세히]        │
            └──────────────────────────────────────────────────────────┘

                         ☀ 푸드·건강 (주황 클러스터)
                        /        |        \
                   안정        취향        호기심
                      \                    /
   관계·연결 ●────────  ◎ 나의 우주(아바타)  ────────● 삶·균형 (민트)
   (자홍)                    │                         |
                         계획 · 표현                 루틴 · 회복
```

- **중심 = '나의 우주'(아바타 노드).** 모든 게 여기서 뻗어 나감.
- **1차 가지 = 카테고리/성향 클러스터** (시안의 FOOD&HEALTH / LIFE&BALANCE / ROMANCE&CONNECTIONS 처럼 3~4개, 색으로 구분).
- **2차 노드 = 세부 성향/근거 질문**, 가중치로 크기·링크 두께 결정.
- **모든 인사이트는 '지도 위'에서 인라인으로** 드러남(별도 탭/화면 없음):
  - **오늘의 발견** = 지도 위 상단에 떠 있는 한 줄 카드. 탭하면 관련 노드가 하이라이트되며 지도가 그쪽으로 포커스.
  - **근거 질문** = 노드 탭 시 나오는 콜아웃(시안 #3의 "Connected via 'Consistent Hydration'…" 처럼).
  - **모순 발견(상황별 다른 나)** = 카테고리별로 다르게 나타나는 성향 노드에 **분기 배지(◑)** 표시 → 탭하면 비교 콜아웃.

## 4. 정보구조 변경 (3탭 → 1뷰 + 인터랙션 레이어)

| 기존 (3탭) | 변경 (단일 마음 지도) |
|---|---|
| **발견** 탭(인사이트 카드 + 모순 카드) | 지도 위 **상단 한 줄 헤드라인** + 노드 **콜아웃**으로 흡수 |
| **섬 지형** 탭(공간 존) | 방사형 마인드맵의 **가지 크기/배치**로 흡수(공간감은 레이아웃으로) |
| **별자리** 탭(추상 그래프) | **이 단일 지도 자체**가 별자리. depth/포커스는 탭 인터랙션으로 |

> 결과: **탭 0개.** 화면은 하나, 깊이는 손가락으로.

---

## 5. 인터랙션 모델 (단순하게)

1. **기본(Overview):** 중심 + 1차 클러스터 3~4개 + 상단 발견 한 줄. (노드 10개 내외만 — 과밀 금지)
2. **탭 → 포커스(Obsidian 로컬그래프):** 노드를 누르면 그 노드를 중심으로 부드럽게 재배치, 이웃 노드만 표시 + 하단 콜아웃(점수·근거질문·모순). "전체로" 버튼으로 복귀.
3. **핀치/스크롤 → 줌:** 더 보고 싶으면 확대, 멀어지면 요약.
4. **상단 발견 카드 탭 → 해당 노드로 카메라 이동 + 하이라이트.**
5. 그게 전부. (모드 전환·탭 없음)

## 6. 시각 · 모션 원칙 (트렌디하되 절제)

- **딥 스페이스 1종 테마**(시안 #3): 성운 배경 + 노드별 네온 글로우(클러스터 색 = 기존 `glowByCluster` 토큰: 주황/민트/자홍).
- **동시 표시 최소 + 넉넉한 여백.** 포커스 시 나머지는 흐리게(dim) → 집중 유도.
- **모션 1종:** 포커스 전환의 부드러운 재배치(`react-native-reanimated`) + 노드 은은한 펄싱. 그 외 남발 금지(기존 모션 절제 정책 유지).
- **중심 아바타**는 사용자 프로필 이미지/펫으로 → "내 우주" 느낌.

---

## 7. 데이터 매핑 (백엔드 변경 없음)

기존 `get_personality_insight_graph` 스냅샷을 **그대로** 씀(표현만 통합):

- `nodes`(pet/trait/category/question) → 중심·1차·2차 노드
- `edges` → 방사형 링크(가중치 = 두께)
- `summary` → 상단 "오늘의 발견" 한 줄
- `contradictions`(이미 라이브 적용/병합됨) → 분기 배지 + 콜아웃
- `user_insight_cards` → 포커스 콜아웃 본문

> 서버 RPC 수정 불필요. **클라이언트 표현 레이어만 재구성.**

## 8. 기술 구현 (기존 자산 재활용)

- **재사용:** `InsightGraphCanvas.tsx`(이미 네온 글로우 별자리 구현, 534줄) — 이걸 **단일 메인 뷰의 코어**로 승격. `react-native-svg` + `reanimated`(이미 설치) + `gesture-handler`(포커스/줌 제스처).
- **통폐합(제거/흡수):**
  - `IslandTerrainView.tsx` → 제거(레이아웃으로 흡수) 또는 보관만
  - `ContradictionCard.tsx` → 지도 콜아웃으로 이동
  - `InsightNodeDetailSheet.tsx` → 포커스 콜아웃으로 통합(또는 유지)
  - `InsightMapScreen.tsx` → **탭 제거**, 단일 캔버스 + 상단 발견 오버레이로 재작성
- **신규:** 중심 아바타 노드, 분기(모순) 배지, 상단 발견 오버레이.

## 9. 단계별 실행

1. `InsightMapScreen`에서 **탭 세그먼트 제거**, 단일 캔버스 레이아웃으로 전환.
2. `InsightGraphCanvas`를 **방사형(마인드맵) 레이아웃 + 중심 아바타**로 보강(현재도 그래프지만 중심·클러스터 강조).
3. **탭 포커스(로컬그래프)** + 핀치/줌 제스처 연결(reanimated/gesture-handler).
4. **상단 '오늘의 발견' 오버레이** + 탭 시 노드 포커스.
5. **모순 분기 배지 + 콜아웃**(기존 contradictions 데이터로).
6. 정리: terrain/탭 관련 코드 제거, 검증(typecheck/build/preview).

## 11. 한 페이지 요약

1. **3탭(발견/섬지형/별자리)을 폐기**하고 **단일 '마음 지도'**로 통합 — 시안 #3가 목표.
2. 중심 '나' + 방사형 클러스터(마인드맵) + 로컬그래프 포커스(Obsidian) = **하나의 화면**.
3. 발견·근거질문·모순은 **탭이 아니라 지도 위 오버레이/콜아웃/배지**로.
4. **백엔드 변경 0** — 기존 스냅샷 표현만 재구성.
5. 기존 `InsightGraphCanvas`를 코어로 재활용, terrain/탭 코드는 정리.
6. 트렌디 = 딥스페이스 1테마 + 절제된 모션, 심플 = 동시 표시 최소 + 손가락 점진 공개.
